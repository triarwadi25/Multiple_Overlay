about=Multiple Overlay Tools runs vector overlay operations on many layers in a single step. Intersection Multiple (points, lines, polygons), Union Multiple (same geometry type), Erase Multiple (one layer erased by several polygon layers) and Clip Multiple (many layers clipped by one polygon). For every input layer you can use selected features only, keep only chosen fields and add a field-name prefix. Invalid geometries can be fixed automatically. Works from the Vector menu (Overlay Multiple) and from the Processing Toolbox.
